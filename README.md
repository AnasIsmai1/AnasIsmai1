### Building in the open

**[supacode-companion](https://github.com/AnasIsmai1/supacode-companion)** is a phone dashboard for Claude Code sessions running in Supacode worktrees. It mirrors the project tree, streams the conversations, and sends replies back.

**[enterprise](https://github.com/AnasIsmai1/enterprise)** is the NestJS 11 backend I start every project from. Multi-tenant orgs and invites, TypeORM, Redis with BullMQ, R2, Swagger, Docker.

**[dotfiles](https://github.com/AnasIsmai1/dotfiles)** covers Arch/Hyprland and macOS, managed with Stow. Neovim, zsh, tmux, and an `install.sh` that does it in one shot.

### Shipped for clients

**[Path Tennis](https://pathtennis.com)** finds tournaments for players, coaches and academies. It scrapes 6+ federations, enriches the results with geolocation, then serves personalized suggestions.

**[Sledge](https://getsledge.com)** is an AI operations platform for trade businesses: pipeline, scheduling, job costing. Its OCR engine reads invoice PDFs straight into QuickBooks and Xero.

**[MBA Interview](https://mbainterview.ai)** runs mock interviews tuned to a candidate's resume and target school, with structured scoring, video-essay simulation and subscription billing.

### Stack

TypeScript, Python and Go. Next.js and NestJS over PostgreSQL, Redis and BullMQ. Deployed with Docker and Kubernetes on AWS. The AI side is mostly RAG, OCR and document parsing, and multi-agent orchestration.
